SD-CWT text redaction

A free-text claim carried as {{ chunk_chars }}-character chunks, each one individually redactable. The signed envelope never changes — revealing text only attaches disclosures to the unprotected header.

1 Issue

The signed token is fully redacted: a single hash for the whole field, one hash per chunk inside it, and no disclosures attached.

2 Holder

Select text with the mouse, then reveal or hide it. Start from either side: reveal everything and black out the sensitive parts, or hide everything and open up only what you want to prove.

3 Verify

Checks the issuer signature over the payload, then hash-matches every presented disclosure against the redacted claim hashes it commits to.
